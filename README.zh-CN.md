🏅 基于 React 和 AntV 的优秀组件库 ❤️

**Ant Vision Zoo** 是一个基于 React 和 [AntV](https://antv.vision) 的组件库，提供了很多自定义的独立组件，致力于提高 React 开发者的开发效率和改善开发体验，营造开源友好的环境，共同进步。

## 特性

🪄 开箱即用，助您快速上手，逐梦远方

💎 与 Ant Design 兼容，更多组件不断开发中

🎨 主题支持，随心所欲的由您定制

## 快速开始

您可以在您的 React 项目中使用以下命令来安装本组件库：

```bash
$ npm install @yookue/ant-vision-zoo --save
```

然后，您可以使用以下命令来导入组件：

```jsx | pure
import {Foobar} from '@yookue/ant-vision-zoo';
```

享受您和 `ant-vision-zoo` 的编程之旅吧 ✌️
