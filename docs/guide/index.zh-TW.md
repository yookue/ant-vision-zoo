## 什麽是 `ant-vision-zoo`？

`ant-vision-zoo` 是一款基於 React 和 [Ant Vision](https://antv.vision) 的增強組件庫，提供更多自定義樣式和獨立組件，為 React 開發者提供更好的的組件開發體驗。

## 特性

🪄 熟悉 AntV 可快速上手，讓您專註於業務邏輯

💎 不斷完善的 React 組件，與 AntV 如出一轍

🎨 支持 Ant Design Pro 主題樣式，更多樣式，隨心控製

## 快速上手

### 環境準備

首先得有 [node](https://nodejs.org/en)，並確保 node 版本是 10.13 或以上。

```bash
$ node -v
v10.13.0
```

### 安裝依賴

在您的項目中安裝此依賴：

```bash
$ npm install @yookue/ant-vision-zoo --save
```

### 開始開發

在您的程序中導入組件：

```jsx | pure
import {FooBar} from '@yookue/ant-vision-zoo';
```

即可開始使用 `ant-vision-zoo` 組件編寫您的程序。✌️
