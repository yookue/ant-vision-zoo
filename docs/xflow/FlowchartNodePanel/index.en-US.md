## FlowchartNodePanel

FlowchartNodePanel, provides a panel with some general nodes for dragging and dropping.

With multilingual support, while the `@antv/xflow@1` supports Simplified Chinese only.

### Import

```jsx | pure
import {FlowchartNodePanel} from '@yookue/ant-buddy-pro';
```
