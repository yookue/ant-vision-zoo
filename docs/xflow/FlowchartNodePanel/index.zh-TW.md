## FlowchartNodePanel

FlowchartNodePanel 是一個提供了一些可拖放通用節點的面板。

支持多語言（原生的 `@antv/xflow@1` 只支持簡體中文）。

### 導入組件

```jsx | pure
import {FlowchartNodePanel} from '@yookue/ant-buddy-pro';
```
