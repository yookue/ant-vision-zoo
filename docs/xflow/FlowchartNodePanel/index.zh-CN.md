## FlowchartNodePanel

FlowchartNodePanel 是一个提供了一些可拖放通用节点的面板。

支持多语言（原生的 `@antv/xflow@1` 只支持简体中文）。

### 导入组件

```jsx | pure
import {FlowchartNodePanel} from '@yookue/ant-buddy-pro';
```
