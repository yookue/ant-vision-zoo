## FlowchartFormPanel

FlowchartFormPanel 是一个用来设置节点和线属性的面板。

支持多语言（原生的 `@antv/xflow@1` 只支持简体中文）。

- 某些字段可能不是您选择的语言，这是由于用于演示的 `dumi` 使用了与 `antd` 不同的多语言实现方案，实际在统一的 `antd` 环境下会自动统一。

### 导入组件

```jsx | pure
import {FlowchartFormPanel} from '@yookue/ant-buddy-pro';
```
