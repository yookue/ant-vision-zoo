## FlowchartFormPanel

FlowchartFormPanel 是一個用來設置節點和線屬性的面板。

支持多語言（原生的 `@antv/xflow@1` 只支持簡體中文）。

### 說明

<Alert type='info'>
  某些字段可能不是您選擇的語言，這是由于用于演示的 `dumi` 使用了與 `antd` 不同的多語言實現方案，實際在統一的 `antd` 環境下會自動統一。
</Alert>

### 導入組件

```jsx | pure
import {FlowchartFormPanel} from '@yookue/ant-buddy-pro';
```
