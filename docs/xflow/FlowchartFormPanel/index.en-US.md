## FlowchartFormPanel

FlowchartFormPanel, provides a panel with the abilities to set attributes of nodes and edges.

With multilingual support, while the `@antv/xflow@1` supports Simplified Chinese only.

### Illustration

<Alert type='info'>
  Some fields maybe different from the locale you have chosen, because `dumi` (for demonstration) uses the different intl way of `antd`, these will be ok when runs under `antd`.
</Alert>

### Import

```jsx | pure
import {FlowchartFormPanel} from '@yookue/ant-buddy-pro';
```
