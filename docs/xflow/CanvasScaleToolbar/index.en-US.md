## CanvasScaleToolbar

CanvasScaleToolbar, provides a toolbar with the abilities to zoom and toggle fullscreen.

With multilingual support, while the `@antv/xflow@1` supports Simplified Chinese only.

### Import

```jsx | pure
import {CanvasScaleToolbar} from '@yookue/ant-buddy-pro';
```
