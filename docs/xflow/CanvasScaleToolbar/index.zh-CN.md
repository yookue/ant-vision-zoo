## CanvasScaleToolbar

CanvasScaleToolbar 是一个用来切换缩放和全屏的工具栏。

支持多语言（原生的 `@antv/xflow@1` 只支持简体中文）。

### 导入组件

```jsx | pure
import {CanvasScaleToolbar} from '@yookue/ant-buddy-pro';
```
