## CanvasScaleToolbar

CanvasScaleToolbar 是一個用來切換縮放和全屏的工具欄。

支持多語言（原生的 `@antv/xflow@1` 只支持簡體中文）。

### 導入組件

```jsx | pure
import {CanvasScaleToolbar} from '@yookue/ant-buddy-pro';
```
