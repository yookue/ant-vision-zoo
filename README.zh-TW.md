🏅 基於 React 和 AntV 的優秀組件庫 ❤️

**Ant Vision Zoo** 是壹個基於 React 和 [AntV](https://antv.vision) 的組件庫，提供了很多自定義的獨立組件，致力於提高 React 開發者的開發效率和改善開發體驗，營造開源友好的環境，共同進步。

## 特性

🪄 開箱即用，助您快速上手，逐夢遠方

💎 與 Ant Design 兼容，更多組件不斷開發中

🎨 主題支持，隨心所欲的由您定制

## 快速開始

您可以在您的 React 項目中使用以下命令來安裝本組件庫：

```bash
$ npm install @yookue/ant-vision-zoo --save
```

然後，您可以使用以下命令來導入組件：

```jsx | pure
import {Foobar} from '@yookue/ant-vision-zoo';
```

享受您和 `ant-vision-zoo` 的編程之旅吧 ✌️
